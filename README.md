## 🚀 How to Add to Paperback on iPhone / iPad

1. Open the **Paperback** app on your iOS device.
2. Go to **Settings** (⚙️) > **External Repositories**.
3. Tap **Add Repository** and enter:
   ```text
   https://mrhackpcs.github.io/paperback-thai-source/
   ```
4. Tap **Save**.
5. Install your favorite sources and enjoy reading! 🎉
